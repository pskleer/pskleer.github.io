Question 4

Suppose you want to sell a laptop to a potential buyer. The buyer’s valuation of the laptop is a nonnegative continuous random variable X with distribution \mathbb{P}. The seller sets a price p for the laptop; the buyer will buy the laptop if the realization of X is greater than or equal to the price p.

The expected revenue of the seller is given by p \cdot \mathbb{P}(X \geq p) if the seller sets price p. The optimal price maximizing the revenue is the so-called monopoly price p^* given by \begin{align} p^* = \text{argmax}_{p \geq0 } \, p \cdot \mathbb{P}(X \geq p). \end{align} The monopoly price p^* can be found (under some assumptions we do not worry about here) by solving the equation \begin{align} 1 - F(p)= pf(p) \end{align} where F(p) is the cumulative distribution function (cdf) of X, and f(p) the probability density function (pdf) of X.

Question 5

In this exercise, we will look at the problem of sparse vector approximation.1 You should not use for-loops to answer the questions posed here. Please note that this question is heavy on notation, so part of the learning experience here is also to make sure you understand all the notation and dimensions, and can implement them correctly.

We consider the following setting: We are given a square matrix A \in [0,1]^{n \times n}, a non-negative vector x = [x_0,\dots,x_{n-1}] \in [0,1]^n with \sum_i x_i = 1, and a non-negative vector y = [y_0,\dots,y_{n-1}] \in [0,1]^n with \sum_j y_j = 1.

We can interpret x and y as discrete probability distributions over the column indices \{0,1,\dots,n-1\} and row indices \{0,1,\dots,n-1\} of the matrix A, respectively. That is, we have a random variable X that samples column i with probability x_i for i = 0,1,\dots,n-1, and a random variable Y that samples row j with probability y_j for j = 0,1,\dots,n-1.

The idea of sparse vector approximation is to sample independently a number of column indices c_0,\dots,c_{K-1} \in \{0,1,\dots,n-1\}, i.e., K samples of the random variable X, and row indices r_0,\dots,r_{L-1} \in \{0,1,\dots,n-1\}, i.e., L independent samples of the random variable Y. Note that the c_i do not have to be distinct. The same holds for the r_j. We then consider for k = 0,\dots,K-1 and \ell = 0,\dots,L-1 the absolute difference \begin{equation} |yAx - y^{(\ell)}Ax^{(k)}| \end{equation} where x^{(k)} = \frac{1}{k+1}\sum_{i=0}^{k} e^{c_i} \ \ \text{ and } \ \ y^{(\ell)} = \frac{1}{\ell+1}\sum_{i=0}^{\ell} (f^{r_i})^T with e^j \in \{0,1\}^n the unit column vector given by e^{j}_i = \left\{ \begin{array}{ll} 1 & \text{ if } i = j\\ 0 & \text{ if } i \neq j \end{array}\right. for j = 0,\dots,n-1, and similarly (f^{j})^T \in \{0,1\}^n the row vector with a 1 in position j and zeros elsewhere.

Sparse vector approximation now means that the expression above for k and \ell converges to zero as k and \ell grow large (we cap these values at K-1 and L_1 above), and this often happens already for relatively small values (compared to m and n). Informally speaking, y^{(L-1)}Ax^{(K-1)} serves as a good approximation to yAx. We will verify this numerically.

We start with creating an array containing the x^{(k)} and y^{(\ell)} for a given (fixed) collection of row and columns indices. Note that it suffices to define this function for the column indices (why?).
