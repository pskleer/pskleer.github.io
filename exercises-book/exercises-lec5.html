Question 2

We will write a function that can compute a root of a polynomial function.

  1. Write a function that takes as input a number x and an array of coefficients a = [a_0,\dots,a_{n-1}]. It should return the function value f(x) = \sum_{i=0}^{n-1} a_i x^i.

The derivative of f is given by f'(x) = \sum_{i=1}^{n-1} i \cdot a_ix^{i-1}.

  1. Write a function f_deriv that takes as input a number x and an array of coefficients a = [a_0,\dots,a_{n-1}]. It should return the derivative f'(x) of f at the point x.

  2. Write a function root_polynomial that takes as input an array of coefficients a = [a_0,\dots,a_{n-1}] and an initial guess r. It should output a root of the function f if one is found, and a message saying no (real) root was found otherwise. Use root_scalar() with Newton’s method and initial guess r.

Question 3

In this problem, we try to solve the 2-by-2 nonlinear system of equations f(x)=0 introduced by Bloggs where

f(x) = \begin{bmatrix} f_0(x) \\ f_1(x) \end{bmatrix} = \begin{bmatrix} x_0^2 - x_1 + 1 \\ x_0 - \cos(\tfrac{\pi}{2} x_1) \end{bmatrix}

with Jacobian

J_f(x) = \begin{bmatrix} 2x_0 & -1 \\ 1 & \tfrac{\pi}{2} \sin(\tfrac{\pi}{2} x_1) \end{bmatrix}.

The problem has solutions (-1, 2), (0, 1), and (-1/\sqrt{2}, 3/2). The goal of this exercise is to show that the root() function might, or might not, converge depending on the initial guess that we choose.

  1. Implement f and its Jacobian as Python functions called f and jac_f.

For initial guesses, we will take points on the circle with radius 2 centered around (0,0). This circle can be parameterized by [2\cos(\rho),2\sin(\rho)] for \rho \in [0,2\pi].

You may use a for-loop to iterate over the values for \rho; the output should include for every \rho a short message including 1) the initial guess and 2) the root that was found, or a message that no root was found.

Question 4

Let A \in \mathbb{R}^{n \times n} be a symmetric, two-dimensional array, b \in \mathbb{R}^n a one-dimensional array and c \in \mathbb{R} a scalar. Consider the function f(x) = f(x_0,\dots,x_{n-1}) = \frac{1}{2}x^TAx + b^Tx + c = \frac{1}{2}\sum_{i = 0}^{n-1} \sum_{j = 0}^{n-1} a_{ij}x_ix_j + \sum_{i=0}^{n-1} b_ix_i + c that takes as input a one-dimensional array x. The gradient of this function is given by \nabla f(x) = Ax + b. If the matrix A has positive eigenvalues, then f is guaranteed to have a minimizer.

Write a function quadratic_minimizer that takes as input A,b and c. It should compute a (local) minimizer of the function f using minimize() with gradient information, the 'CG' method, and initial guess x = [1,1,\dots,1].

It should give the following output on the given input.

# Example usage
A = np.array([[3, 0, 0], [0, 4, 0], [0, 0, 5]])
b = np.array([-1, -4, 1])
c = 6

result = quadratic_minimizer(A, b, c)
print("Optimal solution:", result.x)
print("Function value at optimal point:", result.fun)
Optimal solution: [ 0.333  1.000 -0.200]
Function value at optimal point: 3.7333333333333325

Because the matrix A is symmetric and has positive eigenvalues, the function f is convex, meaning that an optimal solution can be found at the point where the gradient is the all-zeros vector, that is, x^* = -A^{-1}b. This is indeed the solution that we found.

eig_A, _ = np.linalg.eig(A)

print(f"The eigenvalues of A are {eig_A}")

# Solution to gradient = 0
x = -1*(np.linalg.inv(A) @ b)

print("Point where gradient is zero:", x)
print("Function value at point where gradient is zero:", f(x,A,b,c))
The eigenvalues of A are [3.000 4.000 5.000]
Point where gradient is zero: [ 0.333  1.000 -0.200]
Function value at point where gradient is zero: 3.7333333333333334

Question 5

Write a function capacitated_norm() taking as input vectors a, b, w \in \mathbb{R}_{\geq 0}^n, with a \leq b, and a capacity value W that returns the solution x = [x_0,\dots,x_{n-1}] to the problem

\begin{array}{ll} \max & \displaystyle \sqrt{\sum_{i=0}^{n-1} x_i^2} \\ \text{s.t.} & \displaystyle \sum_{i=0}^{n-1} w_i x_i \leq W \\ & a_i \leq x_i \leq b_i \text{ for } i = 0,\dots,n-1 \end{array}

using minimize() with the 'trust-constr' method. Take a as the initial guess. You may assume that \sum_i w_ia_i \leq W, so that this problem always has a non-empty feasible region.

Hint: You may want to have a look at the constraints keyword argument in the documentation of minimize() to see how you can pass additional arguments to a constraint.

# Input data
n = 7
a = np.array([0,0,1,4,1,0,7])
b = np.array([1,4,3,6,8,1,9])
w = np.array([0,6,5,4,6,5,3])
W = 2*np.sum(w*a)

# Compute solution
x = capacitated_norm(a,b,w,W)

# Print solution
print(x)
